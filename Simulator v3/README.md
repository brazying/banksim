# bankSim — симулятор банковского счёта и инвестиционного портфеля

Учебное desktop-приложение на Python, PyQt6, SQLite и Matplotlib.

## Возможности
- Банковский счёт: доходы, расходы, пополнения, снятия и история операций.
- Симулируемый рынок акций с автоматическим изменением котировок.
- Покупка и продажа акций, средняя цена приобретения и реализованная прибыль.
- Рынок облигаций: покупка, продажа, купонные выплаты и погашение.
- Общий инвестиционный портфель и оценка текущей стоимости активов.
- Калькулятор вкладов со сложными процентами.
- Монте-Карло моделирование капитала с диапазоном сценариев.
- График общего капитала с детализацией по часам, дням, неделям и месяцам.
- Отчёты о денежных потоках, расходах, портфеле и инвестиционном результате.
- Локальное хранение данных в SQLite и интерфейс на русском языке.

Все компании, котировки и финансовые сценарии в приложении учебные. Приложение не подключается к реальному банку или бирже и не использует настоящие деньги. При первом запуске создаётся демонстрационный баланс 10 000 ₽.

## Демонстрация и защита

Порядок показа функций, рекомендуемые значения для демонстрационных операций и контрольный список перед защитой находятся в [DEMO_GUIDE.md](DEMO_GUIDE.md).

## Структура проекта
Основной код находится в папке `Simulator v3`:
- `main.py` — запуск приложения и навигация.
- `pages.py` — страницы интерфейса.
- `database.py` — SQLite и учёт операций.
- `finance.py` — финансовые расчёты.
- `charts.py` и `theme.py` — графики и оформление.
- `tests/` — автоматические тесты финансовой логики и сценариев интерфейса.
- `DEMO_GUIDE.md` — сценарий демонстрации проекта.

## Запуск в Windows

Самый простой вариант — запустить `start_bankSim.bat` двойным щелчком. Скрипт создаёт виртуальное окружение, при необходимости устанавливает зависимости и открывает приложение.

Вручную: открой CMD в папке `Simulator v3` и выполни:

```cmd
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py main.py
```

База данных создаётся автоматически в `Simulator v3/data/ledger.sqlite3`. Она хранится локально и исключена из Git.

## Запуск тестов
Из папки `Simulator v3`:

```cmd
py -m unittest discover -s tests -v
```
