# LEDGER — Финансовый симулятор

Учебное desktop-приложение на Python, PyQt6 и SQLite.

## Возможности
- Баланс счёта: доходы, расходы, пополнения, снятия и денежный эффект биржевых сделок.
- Встроенный симулируемый рынок из восьми вымышленных акций.
- Автоматические случайные колебания котировок примерно раз в 15 секунд (ограниченные по размеру).
- Покупка и продажа акций с проверкой доступного баланса и количества бумаг.
- Портфель акций, средняя цена покупки и текущая стоимость.
- Калькулятор сложных процентов, прогноз капитала и отчёты.
- График баланса и диаграмма структуры активов.
- Интерфейс на русском языке.

Все компании и цены вымышлены. Приложение работает локально, не подключается к реальному банку или бирже и не использует настоящие деньги. Для первой проверки создаётся демонстрационный баланс 10 000 ₽.

## Запуск в Windows
Открой CMD в папке `bank_simulator` и выполни по очереди:

```cmd
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
py main.py
```

База создаётся автоматически в `data/ledger.sqlite3`.
